# axel-labler frontend

Angular UI of Axel Labler. Build, run and test it via Docker; see the repository README.

Styling: Bootstrap 5 (CSS only, bundled from npm through `angular.json`; no Bootstrap JS). Angular
signals toggle its dropdown, modal and toast classes. `src/styles.css` maps the dark/light theme
(`data-bs-theme`) and the app colour tokens onto it.
